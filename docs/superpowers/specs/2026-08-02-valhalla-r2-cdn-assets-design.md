# Valhalla R2 CDN Assets Design

## Goal

Move Valhalla Strapi media URLs to the same public shape used by the Tibia project:

- DEV: `https://cdn-dev.valhallatecnologia.com.br/assets/images/...`
- PROD: `https://cdn.valhallatecnologia.com.br/assets/images/...`

The project keeps one Cloudflare R2 bucket. Environment separation is handled by the public CDN hostname, while Strapi uses the same object prefix, `assets/images`, in both environments.

## Current State

Strapi uses the official AWS S3 upload provider against Cloudflare R2 in `config/plugins.ts`.

Current media records migrated from DEV to PROD point to the DEV R2 public domain and `uploads-dev` path. The last content transfer intentionally used `--only content`, so production content exists and images resolve through the existing DEV R2 objects.

Current relevant env model:

- `R2_BUCKET=valhalla-media`
- `R2_ENDPOINT=https://f4651f9fada394b0e0ab5cd309e5fb11.r2.cloudflarestorage.com`
- `R2_PUBLIC_URL` varies by environment
- `R2_ROOT_PATH` currently varies by environment

## Target Env Model

Both environments keep the same R2 bucket and root path. Only the public base URL changes:

```env
# DEV
R2_BUCKET=valhalla-media
R2_PUBLIC_URL=https://cdn-dev.valhallatecnologia.com.br
R2_ROOT_PATH=assets/images

# PROD
R2_BUCKET=valhalla-media
R2_PUBLIC_URL=https://cdn.valhallatecnologia.com.br
R2_ROOT_PATH=assets/images
```

`config/plugins.ts` should continue to derive `baseUrl` from `R2_PUBLIC_URL` and `rootPath` from `R2_ROOT_PATH`. No provider change is required.

`config/middlewares.ts` already adds `R2_PUBLIC_URL` to the CSP media origins, so each deployed environment will allow its own CDN host after env updates and redeploy.

## Object Migration

Existing R2 objects under `uploads-dev/...` must be copied to `assets/images/...`.

The migration should preserve the original filenames generated by Strapi, including thumbnails and responsive formats. Example:

```text
uploads-dev/Air_Cooler_..._8a655366b8.webp
assets/images/Air_Cooler_..._8a655366b8.webp
```

The migration must be copy-first. Do not delete old `uploads-dev` objects until both DEV and PROD have been validated against the new CDN URLs.

## Strapi Media Record Migration

After the object copy, Strapi media records must be updated so every file URL and every nested `formats.*.url` uses the new environment CDN:

- DEV records become `https://cdn-dev.valhallatecnologia.com.br/assets/images/...`
- PROD records become `https://cdn.valhallatecnologia.com.br/assets/images/...`

This update is data-level work against each environment's Strapi database or through a controlled in-process script. It must not recreate products or media records, because existing product relations already point to the correct media records.

The update should be idempotent:

- URLs already using the target CDN are left unchanged.
- Old `pub-*.r2.dev/uploads-dev/...` URLs are rewritten.
- Old `pub-*.r2.dev/uploads/...` URLs are also rewritten because they appeared during the local transfer bridge.

## Operational Steps

1. Configure Cloudflare DNS/custom domains:
   - `cdn-dev.valhallatecnologia.com.br`
   - `cdn.valhallatecnologia.com.br`
2. Ensure both hostnames serve the `valhalla-media` R2 bucket.
3. Update Dokploy env files:
   - DEV `R2_PUBLIC_URL=https://cdn-dev.valhallatecnologia.com.br`
   - PROD `R2_PUBLIC_URL=https://cdn.valhallatecnologia.com.br`
   - both `R2_ROOT_PATH=assets/images`
4. Copy existing R2 objects from `uploads-dev/` to `assets/images/`.
5. Update DEV media records to `cdn-dev`.
6. Update PROD media records to `cdn`.
7. Redeploy both Strapi services so new uploads use `assets/images`.

## Validation

Validation must confirm both data and asset delivery:

- DEV and PROD content counts still match for products, categories, brands, FAQs and policies.
- A product in DEV returns a `mainImage.url` under `https://cdn-dev.valhallatecnologia.com.br/assets/images/`.
- A product in PROD returns a `mainImage.url` under `https://cdn.valhallatecnologia.com.br/assets/images/`.
- Each sampled image URL responds with HTTP 200.
- New uploads in each Strapi environment receive the expected CDN host and `assets/images` path.

## Non-Goals

- Do not introduce a second R2 bucket.
- Do not move Valhalla to Tibia's static asset catalog architecture; Valhalla media remains Strapi-managed upload media.
- Do not delete legacy `uploads-dev` objects during the first migration.
